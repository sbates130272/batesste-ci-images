# cloud-init packages for the "rocjitsu" guest flavour: the toolchain and
# kernel headers amdgpu-dkms needs, plus what every consumer of an emulated
# gfx1250 guest goes on to build with.
#
# ROCm userspace and amdgpu-dkms are *not* here.  They come from third-party
# apt repositories, which cloud-init's package list cannot add, so they are
# installed by provision/rocjitsu.sh in a provisioning boot instead.
#
# Nothing here may be kernel-versioned: cloud-init runs before any of the
# provisioning does, and ${KERNEL_VERSION} expands to the *host* kernel.
build-essential
cmake
ninja-build
pkg-config
dkms
git
# No kernel metapackage here, deliberately.  Which one to install, and whether
# it goes in before or after amdgpu-dkms, depends on the release, and
# provision/rocjitsu.sh is where that decision lives:
#
#   resolute -- the cloud image already boots 7.0, so the DKMS module builds
#     for the kernel that matters and the HWE metapackage is only a roll
#     forward to the latest 7.0.0-3x.
#   noble -- amdgpu-dkms's postinst builds for every kernel with headers on
#     disk rather than for the running one, and the noble package's kcl layer
#     does not compile against 7.0 at all, so the HWE kernel must not be here:
#     naming it would put 7.0 headers on disk before provisioning even starts.
#
# Headers for the kernel the cloud image boots are needed either way.
linux-headers-generic
# Needed before the provisioning boot can add a signed apt source.
ca-certificates
curl
gnupg

# rocm-xio's build and test dependencies, pre-installed because every consumer
# of this flavour wants them and they are free to carry.
libcli11-dev
libdrm-dev
libssl-dev
nvme-cli
pciutils
python3-dev
rsync

pipx
python3-venv
